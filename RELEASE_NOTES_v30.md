# KURSOR 2.10.0 — AlfaCRM import release

## Главное

- Полный экспорт клиентов AlfaCRM загружается напрямую без ручного преобразования колонок.
- Импорт поддерживает несколько активных групп у одного ученика и несколько телефонов в одной ячейке.
- Недостающие группы и филиал создаются автоматически; расписание извлекается из названия группы.
- Предварительная проверка показывает создаваемые группы и отдельно отмечает группы без распознаваемого расписания.
- Внешний AlfaCRM ID сохраняется в CRM и предотвращает дубли при повторной загрузке того же файла.
- Импорт с ошибками не начинает запись и не оставляет частично созданную структуру.

## Данные релиза

- Версия приложения: `2.10.0`.
- Версия схемы: `22`.
- Frontend cache key: `v30`.
